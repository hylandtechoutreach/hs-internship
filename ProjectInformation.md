# HYLAND TECH OUTREACH PORTAL (HyTOP)
_an online IDE for Hyland Tech Outreach programs_

## Description
This application allows Hyland Tech Outreach students to create, store, edit, share, and host web-based code projects.

### Background & Motivation
For years, the Tech Outreach team has tried to find an online IDE that works. We have struggled immensely, especially because things change constantly. New features are added and old features are removed, price tiers shift, bugs pop up... it's hard to keep up. This project will be enormously helpful for our team, to help facilitate all of our programs effectively!

## Summer Goals
Right now, [HyTOP](https://hytop.onrender.com) can do everything it _needs_ to do! With HyTOP, students can build and host their own websites. However, it can and should do more.

Here are some of the primary goals for the summer:

- Bug Finding / Fixing
- Small Nice Features
- Admin / Classroom View
- Python Support (research required)
- Password Reset Process (additional service required)
